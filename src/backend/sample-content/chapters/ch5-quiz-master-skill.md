# Quiz Master Skill

## Overview

The **Quiz Master** creates and administers interactive quizzes, providing immediate feedback.

## Quiz Types

| Type | Description |
|------|-------------|
| Multiple Choice | Select from options |
| True/False | Binary choice |
| Fill in the Blank | Complete the statement |
| Matching | Pair related items |

## Feedback Strategies

1. **Immediate Feedback**: Provide feedback right after each answer
2. **Explanatory Feedback**: Explain why an answer is right or wrong
3. **Encouraging Feedback**: Keep learners motivated

## Key Takeaways

1. Quiz Master administers interactive assessments
2. Provides immediate, explanatory feedback
3. Tracks progress throughout the quiz session
